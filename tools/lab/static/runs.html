Everything one benchmark run measured, its arms ranked against each other. BlockScore is the worst pillar, in units of this run's own real sample spread — 0 is held-out real, lower is better. Pillars are never averaged: a mean would let an arm buy a bad pillar with a good one, and the render tier invites exactly that trade (T25e). The cross-run leaderboard ranks models instead — these scores are calibrated within this run and are not comparable across runs unless both ran the same protocol.
