BlockLab

A local instrument over the artifacts this repo already writes — look at builds, label them, and read a scorecard without rerunning the batch.

Tools

Curate

Triage a dataset build by build. Keyboard-first: g b u label, arrows move, n notes.

Leaderboard

A scorecard from blockgen.eval.bench, with the pairwise verdicts behind each ranking.

Compare

Two builds, one decision. Forced-choice pairs logged with response time.

Gates

Try a curation threshold and see what it keeps and drops, before rebuilding a dataset.

Datasets

Nesting is derivation: a child came out of its parent. Counts are per node and never double-counted, so a corpus total excludes its own splits and branches. Branch makes a new named subset of any node.

Export

Decisions made here are proposals. These files are the seam back into the batch pipeline — nothing is written into a corpus cache.
