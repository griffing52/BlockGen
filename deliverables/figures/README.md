# Proposal figures

Generated by `scripts/figs/proposal_figures.py` (run with the project venv:
`.venv/bin/python scripts/figs/proposal_figures.py`, add `--render` to re-render
the raster assets). Every figure ships as `.svg` (master, live text, embedded
images) + `.pdf` (Inkscape export, text stays text, images embedded at full
resolution) + `.png` (220 dpi preview only). Open the SVG or PDF in Illustrator.

| file | what it is | use |
|---|---|---|
| `proposal_overview.*` | the three-panel figure: (a) one-shot prediction with one wrong cell, (b) property cards, (c) constructive policy loop + Execute box, with the Aims strip underneath | Fig. 1 / the "map of the plan" |
| `proposal_card_anatomy.*` | one card dissected (footprint, ports, behaviour, test) and the same schema for a Minecraft block, a Redstone part and a LEGO brick | Aim 1 |
| `proposal_action_mask.*` | the action (u, v, e) and the three masks (port types, geometry, budget) as pictograms | Aim 2 |
| `proposal_compounding.*` | P(all N cells correct) = p^N for three per-cell accuracies; pure arithmetic, labelled illustrative | intro / motivation |
| `proposal_timeline.*` | three-year Gantt with placeholder milestones | management plan |
| `proposal_gallery.*` | loose imagery strip: cabin that executes vs one wrong cell, the block deck, the LEGO cabin | spare parts |

## Assets (`assets/`)

Trimmed RGBA PNGs you can relink or reuse directly:

* `house_ok.png`, `house_wrong.png`: a synthetic 9x8x9 cabin built in the
  script (no corpus data, so no licensing question), rendered with
  `blockgen.renderer.textured` using the vanilla texture pack. The wrong
  version has one red wool block sealing the doorway.
* `block_*.png`: single-block renders (planks, log, cobble, glass, lamp,
  redstone block).
* `lego_cabin.png`: LDraw OMR set 31048-1 "Small Cabin", rendered earlier for
  the paper (Blender/Cycles, cached in `outputs/figstage/lego_ldraw_work`).
  OMR files are CC BY; credit "LDraw.org OMR, 31048-1 Small Cabin (CC BY)" if
  it appears in the proposal.

## Conventions

* Fonts: Helvetica/Arial stack, 9 pt minimum (titles 10 pt). The PDF embeds
  Nimbus Sans as the substitute; Illustrator will offer to swap it.
* Ports: inputs = blue filled circle, outputs = orange filled square,
  undirected attach = open grey circle. Shape differs so it survives grayscale.
* Status: valid = green badge with check + solid line; masked/fail = red badge
  with cross, dashed grey line. Never colour alone.
* Notation matches the text: G_t, (u, v, e), pi(u, v, e | G_t).
* Minecraft renders use Mojang's textures. The paper renders flat for EULA
  reasons (see `scripts/paper_figures.py`); for an internal proposal that is
  usually fine, but swap to flat renders if the document will be public.
